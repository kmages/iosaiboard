# FixKey

A one-button iOS keyboard. Type with your usual keyboard, switch to FixKey, tap Fix.
Claude corrects spelling and grammar and leaves the wording alone.

- `ios/` the app and keyboard extension (Swift, project generated by XcodeGen)
- `proxy/` the server the keyboard talks to. It holds the Claude API key and stores no text.

## Server

Runs on the openbrain box as `fixkey.service` on port 8091, behind nginx at
`https://fixkey.5-161-180-197.nip.io`. Settings live in `/etc/fixkey.env`:

    FIXKEY_TOKEN=...        shared secret the app sends
    ANTHROPIC_API_KEY=...   Claude key from the Console

After editing: `sudo systemctl restart fixkey`. Logs: `journalctl -u fixkey -f`.

## Build on a Mac

    brew install xcodegen
    scp -r ken@5.161.180.197:fixkey/ios ~/fixkey-ios && cd ~/fixkey-ios
    xcodegen && open FixKey.xcodeproj

The copy includes `Shared/Config.swift`, which holds the token and is not in git.

Pick your iPhone as the run target and press Run. Then on the phone:
Settings > General > Keyboard > Keyboards > Add New Keyboard > FixKey, and turn on Allow Full Access.

## What it fixes

The selected text if there is a selection, otherwise the text before the cursor.
iOS only shows a keyboard the text near the cursor, so for a long multi-paragraph
message, select all first.
